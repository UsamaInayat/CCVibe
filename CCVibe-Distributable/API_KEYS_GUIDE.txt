========================================
     CCVibe - API Keys Setup Guide
========================================

CCVibe needs API keys to translate messages.
You can use Google, an AI provider, or both for the best experience.

Both Hindi/Urdu AND Indonesian use the same keys.


OPTION 1: Google Translate API Key (Recommended - Free Tier)
------------------------------------------------------------

1. Go to: https://console.cloud.google.com/
2. Sign in with your Google account
3. Create a new project (or select an existing one)
4. Enable the "Cloud Translation API":
   - Go to APIs & Services > Library
   - Search "Cloud Translation API"
   - Click Enable
5. Create an API key:
   - Go to APIs & Services > Credentials
   - Click "+ Create Credentials" > "API Key"
   - Copy the key (starts with AIzaSy...)
6. Paste it in Discord:
   Settings > Vencord > Plugins > CCVibe (gear icon) > Google Translate API Key

Free Tier: 500,000 characters/month at no cost.

IMPORTANT:
- If you get 403 errors, check API key restrictions in Google Cloud Console.
- Under API restrictions, allow "Cloud Translation API".
- Make sure the key belongs to the same project where Cloud Translation API is enabled.


OPTION 2: AI Provider API Key (Slang & Conversational Text)
------------------------------------------------------------

CCVibe supports any OpenAI-compatible API. Pick one provider in settings:

  Groq (default, free tier)
  - https://console.groq.com/keys
  - Key starts with gsk_
  - Default model: llama-3.3-70b-versatile

  DeepSeek
  - https://platform.deepseek.com/api_keys
  - Key starts with sk-
  - Default model: deepseek-chat

  OpenRouter (access many models with one key)
  - https://openrouter.ai/keys
  - Key starts with sk-or-
  - Default model: deepseek/deepseek-chat

  OpenAI
  - https://platform.openai.com/api-keys
  - Key starts with sk-
  - Default model: gpt-4o-mini

  Custom
  - Any OpenAI-compatible endpoint (local LLM, other hosts)
  - Set Custom API URL in CCVibe settings
  - Set your model name in AI Model override

Enter your key in:
  Settings > Vencord > Plugins > CCVibe > AI API Key

Optional: override the model name in "AI Model override".


TRANSLATION STRATEGY
--------------------

In CCVibe settings, choose how translations are routed:

  Fast        — Google first, AI as fallback (best for speed)
  Balanced    — Same as Fast (recommended for most users)
  Quality     — AI first for slang/conversations, Google as fallback


WHICH KEYS SHOULD I USE?
------------------------

Best experience: Set up BOTH Google + an AI key.

CCVibe routing:
  - Google Translate  ->  Short phrases, literal translations
  - AI (Groq/DeepSeek/etc) ->  Slang, conversations, context
  - Dictionary        ->  Common words (no key needed)
  - Word-by-word      ->  Abbreviation-heavy text (no key needed)

If you only want one: Google covers most cases.
If you set neither: Dictionary and word-by-word still work for common words.


WHERE TO ENTER KEYS
-------------------

1. Open Discord
2. Click the gear icon (Settings)
3. Scroll down to "Vencord" section
4. Click "Plugins"
5. Find "CCVibe" and click the gear icon next to it
6. Enter your API key(s)
7. Done! No restart needed.
